# Step 2 — Confirm Assets With The User

Before building, ask the user two questions (you may ask both at once):

## 1. Hero image
> "Please provide a hero/banner image for the wizard. This sits directly below the header bar and sets the visual tone for the product (e.g. parking photography, travel imagery). If you don't have one yet, I can use a placeholder."

## 2. Product name
> "What is the product name to display alongside the logo in the header bar? (e.g. 'Airport Parking', 'Travel Insurance', 'Airport Transfers')"

## Gate
Do **not** proceed to build the wizard until you have these answers (or the user explicitly says to proceed with placeholders).

## No fallback
A real photo or video is required for the hero area. Do not fall back to a gradient or placeholder. If none has been supplied, ask again:
> "A real photo or video is required for the hero area. Please provide one before I build the wizard (a placeholder image URL or uploaded file is fine)."
