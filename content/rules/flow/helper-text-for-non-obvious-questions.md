# Helper Text For Non-Obvious Questions

Every step that asks something non-obvious must include helper text below the options. This answers "why are you asking me this?" or "what if I don't know?".

## Placement
- **Below** the options. Never above.
- Inside a `.helper-card` block.

## Rules
- **Bold the key term** at the start ("**Not sure of the exact time?**", "**Flights can be unpredictable.**")
- Keep it under 3 sentences
- Never use helper text as a substitute for a clearer question — fix the question first
- Mention add-on products (e.g. Overstay Waiver, Flextras) only where genuinely relevant

## When NOT to add helper text
- The question is genuinely self-explanatory ("Flying from", with a list of airports)
- The user has already been told the same thing on a previous step

## Examples
- Drop-off time: "**Not sure of the exact time?** Don't worry — most car parks allow you to arrive up to 3 hours either side of your booked drop-off time…"
- Cruise: "From missed ports to cabin confinement, additional baggage cover and itinerary changes, our cruise cover helps with the extras."
