# Core Principle — Remove Uncertainty

> Every step a customer takes should remove uncertainty, not create it.

Every question asked, every answer captured, every result shown should leave the customer more confident than before.

When a step makes the customer less certain — because it asks too much at once, because it doesn't explain why, because it dumps results without context — the system has failed.

This is the underlying intent that all other patterns serve.
