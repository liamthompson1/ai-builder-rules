# One Thing At A Time

Each screen asks exactly one question and collects exactly one type of input. The next screen does not appear until that one thing is answered.

## Why
Customers do not experience forms as sets of related fields — they experience them as individual decisions. When multiple questions appear together, the customer must mentally sequence them before they can begin. One question per screen removes that overhead entirely.

## In practice
- The Parking wizard separates airport, departure date, departure time, return date and return time into five distinct screens.
- The Insurance wizard never asks about destination and cover type on the same screen.

## The test
If you removed one question from a screen and made it its own screen, would the journey feel more focused or more fragmented? If more focused — split it.
